# /docs — Documentation Review

## Purpose
Review and update project documentation for completeness, accuracy, and clarity.

## Orchestration
1. Invoke `agent-documentation`
2. Reference `documentation-review` skill
3. Reference `markdown-validation` skill

## Output
Documentation review report with suggested updates.

## Usage
```
/docs [--check] [--update]
```

## Verification
- [ ] README is accurate
- [ ] SPEC matches implementation
- [ ] No outdated information
- [ ] Cross-references valid
