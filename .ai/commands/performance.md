# /performance — Performance Analysis

## Purpose
Analyze performance characteristics: time complexity, memory usage, bottlenecks, scalability.

## Orchestration
1. Invoke `agent-performance`
2. Reference `performance-review` skill

## Output
Performance analysis report with optimization recommendations.

## Usage
```
/performance [--path <path>]
```
