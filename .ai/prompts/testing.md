# Testing Prompt

## Purpose
Prompt an AI to write or review tests.

## Template
```
Write tests for [component/function].

Cover:
1. Happy path — expected behavior
2. Edge cases — boundary conditions
3. Error cases — invalid inputs, failures
4. Determinism — same input, same output

Use [test framework]. Follow existing test patterns in [test file reference].
```

## Usage
Use when adding test coverage. Load `.ai/skills/hidden-test-analysis/SKILL.md` first.
