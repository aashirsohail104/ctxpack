# Architecture Prompt

## Purpose
Prompt an AI to analyze or design system architecture.

## Template
```
Analyze the architecture of [project]. Focus on:
1. Module boundaries and responsibilities
2. Data flow between components
3. Dependency relationships
4. Scalability characteristics
5. Architectural patterns used

Provide a structured analysis covering strengths, weaknesses, and recommendations.
```

## Usage
Use when reviewing or designing architecture. Load `.ai/skills/architecture-review/SKILL.md` first.
