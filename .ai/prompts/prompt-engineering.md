# Prompt Engineering Prompt

## Purpose
Prompt an AI to design or optimize prompts for other AIs.

## Template
```
Design a prompt for [task].

Requirements:
1. Clear role definition
2. Specific instructions
3. Structured output format
4. Edge case handling
5. Quality standards

Follow context engineering principles:
- Critical info at start and end
- Progressive disclosure
- Token efficiency
- Signal over noise
```
