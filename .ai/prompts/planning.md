# Planning Prompt

## Purpose
Prompt an AI to create a detailed implementation plan.

## Template
```
Create an implementation plan for [feature/task].

Requirements:
1. [Requirement 1]
2. [Requirement 2]

For each step, specify:
- What files to modify
- What changes to make
- What tests to write
- What to verify

Include a verification checklist.
```

## Usage
Use before implementing any feature. Ensures structured approach.
