# Performance Prompt

## Purpose
Prompt an AI to analyze or optimize performance.

## Template
```
Analyze the performance of [component].

1. Time complexity of each operation
2. Memory usage patterns
3. Bottlenecks and bottlenecks
4. Scalability at [N]x input size

Provide optimization recommendations with expected impact.
```

## Usage
Use when performance is a concern. Load `.ai/skills/performance-review/SKILL.md` first.
