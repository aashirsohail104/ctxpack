# Documentation Prompt

## Purpose
Prompt an AI to write or update documentation.

## Template
```
Update documentation for [project/feature].

Files to update:
- [file]: [what to change]
- [file]: [what to change]

Ensure:
- Accuracy: Description matches actual behavior
- Completeness: No missing sections
- Clarity: Easy to understand
- Consistency: Same terminology throughout

Follow the documentation conventions in .ai/standards/engineering-standards.md.
```

## Usage
Use when writing or reviewing documentation.
