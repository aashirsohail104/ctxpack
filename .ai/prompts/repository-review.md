# Repository Review Prompt

## Purpose
Prompt an AI to perform a repository-level review.

## Template
```
Review the [project] repository:

1. **Structure**: Is the directory layout logical?
2. **Naming**: Do files follow naming conventions?
3. **Cleanliness**: Are there temp/artifact files?
4. **Organization**: Is code properly separated from docs?
5. **Completeness**: Are all necessary files present?

Provide a structured report with actionable recommendations.
```

## Usage
Use for periodic repository health checks.
