# Release Prompt

## Purpose
Prompt an AI to prepare or verify a release.

## Template
```
Prepare release version [version] for [project].

Checklist:
1. [ ] Version updated in all files
2. [ ] CHANGELOG updated
3. [ ] All tests pass
4. [ ] Determinism verified
5. [ ] Documentation current
6. [ ] Git tag created
7. [ ] Release notes written

Report any blockers.
```
